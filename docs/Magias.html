Magias e feitiços

CD

Classe: Batata

O personagem lança um CD em alta velocidade contra os inimigos. O disco funciona como um projétil cortante, causando dano ao atingir o alvo.

SHOCKWAVE

Classe: Latinha

Libera uma descarga elétrica que atinge o inimigo com um choque poderoso. Também pode ser usado para repelir inimigos.

MÚSICAS MELOSAS

Classe: Latinha

Lança uma jukebox explosiva que gruda nos inimigos e detona, causando dano com uma explosão.

FLASH

Classe: Batata

Habilidade que utiliza um efeito de flash, cegando os inimigos.

OVERHEAT

Classe: High Tech

Fica superaquecido, dando dano nos inimigos que estiverem próximos, também repelindo inimigos.

SUPER VENTOINHA

Classe: Batata

Utiliza uma ventoinha para produzir uma corrente de vento, aumentando a velocidade.

RESTART

Classe: Latinha

Reinicia o sistema, curando a vida.
